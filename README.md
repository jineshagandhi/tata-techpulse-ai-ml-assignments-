# Tata TechPulse – Applied AI & ML

This repository contains assignments completed as part of the Tata Technologies TechPulse Applied AI & ML pre-selection course.
It includes practical implementations covering machine learning, deep learning, computer vision, and natural language processing.

| No. | Assignment | Techniques |
|-----|------------|------------|
| 1 | ML Model for Car Mileage Estimation | Linear Regression, EDA |
| 2 | Simulated Driving Agent Behavior | Genetic Algorithm |
| 3 | Data Cleaning and Preprocessing | Missing values, IQR outliers, encoding, scaling |
| 4 | Vehicle Price Prediction | Linear Regression, Decision Tree, Random Forest |
| 5 | Predictive Maintenance from Sensor Logs | Classification on imbalanced sensor data |
| 6 | Traffic Sign Classification using CNN | Convolutional Neural Network, GTSRB |
| 7 | Pedestrian Detection using OpenCV | HOG descriptor with SVM, IoU evaluation |
| 8 | Sentiment Analysis using LSTM | Recurrent network on customer reviews |

Each folder contains its notebook and a README describing the dataset and how to obtain it.
