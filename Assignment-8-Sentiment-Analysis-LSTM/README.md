# Assignment 8: Sentiment Analysis using LSTM

This project classifies automotive customer feedback as positive or negative using an LSTM network built with TensorFlow and Keras.  
Reviews are labelled from their star ratings, converted to sequences with TextVectorization, and evaluated using precision, recall, F1-score, and a confusion matrix.

## Dataset

Amazon Automotive product reviews (5-core), 20,473 reviews with star ratings.

- https://snap.stanford.edu/data/amazon/productGraph/categoryFiles/reviews_Automotive_5.json.gz

Place `reviews_Automotive_5.json.gz` in this folder before running the notebook.
